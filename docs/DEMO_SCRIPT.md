# 3–5 minute demo script

1. **Problem and users (20 seconds):** Campus issues get lost across informal messages. CampusFix gives students a tracked report and staff a shared work queue.
2. **Student account (35 seconds):** Register/sign in, point out the student workspace and session persistence after reload.
3. **Report (45 seconds):** Create a report with category, severity, building, and details. Show the automatically recorded submission event.
4. **Community support (35 seconds):** Open a report from another student, add support, show the count, then show duplicate/self-support protection if time allows.
5. **Staff workflow (60 seconds):** Sign in with the locally created staff account. Show the queue ranked by priority and the category dashboard. Open the report and move it through review and in-progress, adding an update note.
6. **Resolution and student follow-up (35 seconds):** Mark it resolved, return to the student view, and show the latest status/activity and changed metrics.
7. **Engineering (25 seconds):** Explain the scoring formula and server-side staff checks. Close by showing the README and API docs rather than reading code.

Use real local records for the recording and identify any deliberately seeded records as demo data. A short demo recording still needs to be produced and uploaded by the student.
